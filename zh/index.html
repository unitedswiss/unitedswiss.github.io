Ego

非凡的 GPU，
留在暗处。

Apple 芯片所承载的图形处理器，属于有史以来装入计算机的最精良之列。然而，在 Mac 上以虚拟机运行的 Windows 与 Linux 无法使用它们，每一帧都改由中央处理器绘制。这并不正确。在人工智能时代尤其如此：工作正是在 GPU 上完成。

Ego VM 是面向 Apple 芯片的虚拟机管理程序，具备真正的 GPU 加速。Windows 与 Linux 在 Mac 上以其自有图形芯片运行：游戏、专业软件与私有 AI 模型，封存在一台从不离开书桌的机器之中。

算力正成为本世纪的原料。许多人已经拥有的最强硬件，应当完全归他们使用。

VP.NET

信任易逝。
数学则不然。

虚拟专用网络已存在数十年，几乎全部建立在同一个请求之上：信任我们。服务商能看见你访问的每一个网站，并承诺不去查看。但承诺会被改写，公司会被出售，服务器会被查封。

VP.NET 是可验证的隐私。流量在密封的 Intel SGX 飞地内处理，连其自身的工程师也无法打开，任何人都可以用密码学确认其中运行的确切代码。窥探并非政策所禁。它在设计上即不可能。

我们是 VP.NET 的一部分，因为我们相信安全来自数学与验证，而非信任。信任不是常数。证明才是。

bmail

通信值得
一份证明，而非承诺。

电子邮件已有半个世纪，其中大部分仍存放在服务商可以阅读的服务器上。世界上最大的邮箱被扫描、索引，并应要求交出。私密替代方案长期要求普通人自行管理密钥，或仅仅信任运行机器的人。

bmail 源自 bimil，韩语中意为“秘密”，是可验证私密的电子邮件。邮件、日历、联系人与云盘在你自己的设备上以后量子密码学加密，封存于硬件飞地，并绑定公钥透明度。即便 bmail 也无法读取，任何人都可以核验这些证明。

这是同一信念，见诸一个人所保存的最私密记录。一封信应当私密，是因为它可以被证明如此，而非因为有人如此声称。

Dissent

互联网，审查者
承担不起封锁。

迄今每一种规避工具，都运行在审查者能够发现并封禁的服务器上。审查者只需在每台服务器上获胜一次，而假以时日，它总能做到。数亿人生活在这样的高墙之后。

Dissent 是一款只存在于 Cloudflare 之后的 VPN，置身于 Cloudflare 所前置的五分之一网络之中。每一次连接都是带有 Encrypted Client Hello 的普通 HTTPS，与访问数百万合法网站无从区分。要封锁 Dissent，一个国家必须向自己的人民封锁五分之一的互联网。

依赖不被察觉的自由，是脆弱的。剥夺代价过高的自由，是持久的。我们支持后者。
